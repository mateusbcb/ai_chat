# AI Chat

Objetivo desse projeto é aprender a Criar um AI Chat capas de responder de acordo com um contexto e utilizar Agentes para fazer tarefas.

<br>

## Versão 1

Ai Chat basico. <br>
Apenas responde perguntas

## Versão 2
AI Chat basico, com histórico de conversa, capaz de interpretar código HTML e Marckdown, tanto nas perguntas do usuário como nas resposta da AI

<br>

## Versão 3
AI chat agora com abas de conversa e possúe a capacidade de lembrar do histórico de conversa por aba
Trocado o arquivo de Contexto da pasta Storage para a Resource, garantindo que esse arquivo seja enviado para o GIT

## versão 4
Criado os CRUD´s para o projeto fictício com dados fake para a AI conseguir tanto ler como criar novos. <br>
Foram criados novas tabelas (Produtos, Fornecedores e Lojas), assim como tabelas pivo (produto <> fornecedor e produto <> loja). <br>
O Projeto fictício é um CRM básico para gerenciar uma empresa que possui filiais e seus produtos podem estar em várias filiais e providos de vários fornecedores diferentes.

<br>

## versão 5
Adaptado para a LLM ter respostas diferentes casa identifique se é uma conversa comum ou se precisa executar uma TOOLS. <br>
Atualmente em testes e o uso das TOOLS estão limitadas. <br>
Para conversas comuns é usado uma LLM e para uso de TOOLS outra LLM.

<br>

## versão 6
Troca de Scopo do projeto. <br>
Agora o Projeto se trata de um centro de distribuição, CD, com estoque dos produtos, lojas e suas auditorias de vendas (estoque nas lojas e preço de venda), e Status do produto, tanto no CD como nas lojas. <br>

<br>

Ajuste No Front e no Back assim como nas migrations e TOOL´s

<br>

## versão 7
Adicionado Ao TOOLS da LLM a possibilidade de fazer transferencia de produtos para a loja. <br>
Ajustado o Chat aceitar código HTML puro. <br>
Pausa na criação das TOOLS, para implementar o uso de Modelo Local com o LM Studio e na nuvem com o Open AI.

<br>

## Versão 8
Adaptado para usar tanto Local como o uso da OPENAI.
